
# CareerGuru AI

**Your AI-powered career companion.**

CareerGuru AI is a web-based platform designed to help students, freshers, and job seekers prepare for their careers with AI-powered tools for resumes, job descriptions, interview practice, and career development.

🌐 **Live Website:** https://careerguru.pages.dev/

## Features

- **AI Resume Builder** – Create professional resumes.
- **Resume Analyzer** – Analyze resumes and identify areas for improvement.
- **Career Analyzer** – Get career-related insights and guidance.
- **Job Description Analyzer** – Understand job requirements and skills.
- **Interview Practice** – Practice interview questions and improve preparation.
- **AI Career Chat** – Get assistance with career-related questions.
- **Responsive Design** – Use the platform across mobile and desktop devices.
